Über FRAME

FRAME ist ein unabhängiger Mobile-first-Prototyp zum spielerischen Entdecken von Filmen, Serien und Filmschaffenden. Der persönliche Geschmack entsteht aus deinen Swipe-Entscheidungen.

DATEN & BILDER

The Movie Database

Film-, Serien- und Personendaten sowie Poster- und Profilbilder können über die API von TMDB (The Movie Database) bezogen werden.

This product uses the TMDB API but is not endorsed or certified by TMDB.

TMDB besuchen
TMDB ist die primäre externe Datenquelle von FRAME.

STREAMING-VERFÜGBARKEIT

JustWatch

Die in FRAME angezeigten Streaming-, Leih- und Kaufanbieter für Deutschland werden über die Watch-Provider-Daten von TMDB bezogen. Diese Daten stammen aus der Partnerschaft von TMDB mit JustWatch.

Verfügbarkeiten können sich jederzeit ändern. FRAME zeigt die zuletzt von der Datenquelle gemeldeten Informationen.

JustWatch besuchen
JustWatch ist die Quelle für Streaming-Verfügbarkeiten.

OPTIONALE PREISDATEN

Watchmode

Wenn in FRAME konkrete Miet- oder Kaufpreise angezeigt werden, können diese über die Watchmode API ergänzt werden. Ohne Watchmode zeigt FRAME Anbieter und Verfügbarkeitsart, aber keine erfundenen Preise.

Watchmode besuchen
